# HTML Tags Research Using DevTools & MDN

## 1. Wikipedia - HTML Tags

### `<div>` Tag
The `<div>` element is a generic container used to group HTML elements together.

### `<script>` Tag
The `<script>` element is used to embed executable JavaScript code or link an external JavaScript file in an HTML document.

---

## 2. Google HTML Tags

### `<svg>` Tag
The `<svg>` (Scalable Vector Graphics) tag is used to create vector-based graphics directly inside a webpage (lines, shapes, curves).

### `<iframe>` Tag
The `<iframe>` tag is used to embed another webpage or external content inside the current webpage.

---

## 3. YouTube HTML Tags

### `<button>` Tag
The `<button>` tag is an HTML element used to create a clickable button on a webpage.
